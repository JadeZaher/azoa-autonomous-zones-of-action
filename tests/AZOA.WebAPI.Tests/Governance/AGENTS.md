# Governance verification

The current election authority lives in GovernanceProposal and atomic GovernanceCommandReceipt records. Holons are projections and never votes of record. Historical tests built around child-admin authority, pre-vote projection rewriting, early tally and separate best-effort receipts were migrated to this contract; the active track contains the assertion-migration checklist.

GovernanceProposalRewriteTests uses the real HolonManager and a strict store to prove immutable projection fields and interaction/clone refusal. GovernanceVoteOfRecordTests checks cast-time evidence, zero-count options and malformed-ledger refusal. GovernanceCommandValidationTests checks typed invalid input, principal administration and the dedicated ledger dependency guard. Actions/Handlers/GovernanceNodeHandlerTests retains hash-order/collision/cutoff properties. PersonUniquenessGateElectorateScopeTests retains cross-tenant/global person-key arithmetic using the shared fake identity and claim stores; those fakes do not stand in for production election transaction guarantees.

The real transaction coverage is in AZOA.WebAPI.IntegrationTests/Persistence/Surreal/SurrealGovernanceTests: authenticated creation/recovery, cancellation, current evidence/membership checks, revotes, immutable snapshots, forged ballot Holons, policy revisions and command races. The suite uses isolated SurrealDB namespaces and generated schemas. Mock proof rows there exercise persistence boundaries; they are not live provider acceptance evidence.
