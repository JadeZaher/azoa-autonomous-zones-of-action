# Hold recovery

The panel is keyed by authenticated scope. Store every exact participant request
before HTTP, retain it across response loss, and retire it only after success or
server Applied/Obsolete evidence. A changed displayed row alone is not permission
to forget a request. Opening replacement and withdrawal race original acceptance
at the command version, so expired uncommitted consent can be fenced without
discarding its audit. Cost categories and recipient authorization remain separate.
Discovery and refresh never obtain participant signatures. Mandate management and
legacy caller cutover are still being implemented; this panel is not that closure.
