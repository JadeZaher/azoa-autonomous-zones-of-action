# Landing chrome

`chrome.tsx` shares public page styling and navigation. The paper accent is `#A63D15`: it provides approximately 5.45:1 against `#F2EDE3`, while the previous `#C8501E` provided approximately 3.89:1. Dark sections retain their lighter `#E08A5B` accent. A dark card hovered to the deeper orange uses opaque paper text, including its tag, to retain readable contrast. These palette calculations require a browser axe/visual rerun before approval.
